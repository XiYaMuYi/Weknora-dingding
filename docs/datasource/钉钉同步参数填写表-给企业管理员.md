# 钉钉同步参数填写表（给企业管理员）

> 用途：收集 WeKnora 对接钉钉知识库、钉盘和应用机器人的必要参数。  
> 填写方式：能直接拿到 ID 就填写 ID；拿不到 ID 时填写名称、链接、截图说明和操作人成员信息，我们再通过接口查询。  
> 密钥提醒：AppSecret / Client Secret 请通过公司认可的密钥渠道发送，不要直接贴在群聊或普通文档里。
