# WeKnora 角色用户登录使用操作说明

> 适用对象：系统管理员、工作区 Owner/Admin、Contributor、Viewer、普通业务用户。  
> 目标：说明不同账号角色登录后能做什么、不能做什么，以及常见使用流程。  
> 技术安装和运维见：[技术安装部署维护操作说明](./技术安装部署维护操作说明.md)。

---

## 1. 账号和角色总览

WeKnora 有两套主要权限：

| 权限层级 | 角色 | 作用范围 |
|---|---|---|
| 平台级 | SystemAdmin | 跨工作区的平台管理能力 |
| 工作区级 | Owner / Admin / Contributor / Viewer | 当前工作区内资源和成员权限 |

此外还有：

| 身份 | 说明 |
|---|---|
| API Key | 用于脚本或系统集成，在所属工作区内通常按 Admin 处理 |
| 共享空间成员 | 用于跨工作区共享知识库和智能体，仍受共享权限限制 |
| 嵌入访问用户 | 通过网站嵌入 Widget 使用问答，不等同于后台登录用户 |
| IM 用户 | 在企业微信、飞书、钉钉等 IM 中使用 Agent 问答 |

---

## 2. 登录与进入工作区

### 2.1 登录

1. 打开 WeKnora 地址。
2. 输入邮箱/用户名和密码登录。
3. 如果企业启用了 OIDC，点击企业登录入口完成单点登录。

### 2.2 注册

注册方式取决于部署配置：

| 模式 | 用户体验 |
|---|---|
| 公开注册 | 用户可自行注册，注册后自动创建自己的工作区并成为 Owner |
| 邀请制 | 用户必须通过邀请链接或管理员邀请加入 |
| OIDC | 用户通过企业身份登录，具体加入工作区规则由管理员配置 |

### 2.3 切换工作区

登录后可通过用户菜单或工作区切换器切换当前工作区。

注意：

- 你在不同工作区的角色可能不同。
- 当前工作区决定你能看到哪些知识库、智能体、模型和集成。
- 权限判断以当前工作区为准。

## 3. 角色权限速查表

| 功能 | Viewer | Contributor | Admin | Owner | SystemAdmin |
|---|---:|---:|---:|---:|---:|
| 登录、切换工作区 | 是 | 是 | 是 | 是 | 是 |
| 查看知识库、文档、分块 | 是 | 是 | 是 | 是 | 取决于所在工作区 |
| 知识库问答、Agent 对话 | 是 | 是 | 是 | 是 | 取决于所在工作区 |
| 创建知识库 | 否 | 是 | 是 | 是 | 取决于所在工作区 |
| 上传/编辑自己知识库的文档 | 否 | 是 | 是 | 是 | 取决于所在工作区 |
| 编辑他人知识库 | 否 | 否 | 是 | 是 | 取决于所在工作区 |
| 删除知识库 | 否 | 仅自己创建的知识库 | 是 | 是 | 取决于所在工作区 |
| 创建智能体 | 否 | 是 | 是 | 是 | 取决于所在工作区 |
| 编辑自己创建的智能体 | 否 | 是 | 是 | 是 | 取决于所在工作区 |
| 编辑他人智能体 | 否 | 否 | 是 | 是 | 取决于所在工作区 |
| 配置模型、向量库、MCP、网页搜索 | 否 | 否 | 是 | 是 | 取决于所在工作区 |
| 配置数据源、IM、嵌入渠道 | 否 | 否 | 是 | 是 | 取决于所在工作区 |
| 查看工作区成员 | 是 | 是 | 是 | 是 | 取决于所在工作区 |
| 邀请、移除成员、改角色 | 否 | 否 | 否 | 是 | 取决于所在工作区 |
| 重置工作区 API Key | 否 | 否 | 否 | 是 | 取决于所在工作区 |
| 删除工作区 | 否 | 否 | 否 | 是 | 取决于所在工作区 |
| 查看工作区审计日志 | 否 | 否 | 是 | 是 | 取决于所在工作区 |
| 平台级系统设置、系统管理员管理 | 否 | 否 | 否 | 否 | 是 |

说明：

- Contributor 只能维护自己创建的知识库和智能体；他人创建的资源对 Contributor 通常等同只读。
- Admin 可以维护当前工作区内大多数资源和集成，但不能替代 Owner 做最高风险操作。
- Owner 是当前工作区最高权限，每个工作区有且只有一位 Owner。
- SystemAdmin 是平台级角色，不自动等于每个工作区的 Owner。

## 4. SystemAdmin 操作说明

SystemAdmin 适合平台运维或企业超级管理员。

可执行：

- 查看、添加、撤销系统管理员。
- 查看平台级审计日志。
- 管理平台级系统设置。
- 应用默认存储配额到所有租户。
- 管理内置模型等平台级配置。

注意：

- SystemAdmin 不应日常代替业务工作区 Owner 管理业务资料。
- 如果需要进入某个工作区处理问题，应通过合规流程加入该工作区，或使用平台已授权的跨租户能力。

---

## 5. Owner 操作说明

Owner 是某个工作区的最高负责人。

可执行：

- 查看成员列表。
- 邀请成员加入工作区。
- 创建邀请链接。
- 修改成员角色。
- 移除成员。
- 修改工作区信息。
- 重置 API Key。
- 删除工作区。

建议：

- 至少保留一个真实可登录的 Owner。
- 不要把共用机器人账号作为唯一 Owner。
- 定期审查成员角色。

---

## 6. Admin 操作说明

Admin 负责工作区内配置和运维。

可执行：

- 管理模型配置和模型密钥。
- 测试模型、Embedding、Rerank、多模态、ASR。
- 管理向量数据库配置。
- 管理 MCP 服务和工具审批策略。
- 管理网页搜索提供商。
- 管理数据源同步配置和凭证。
- 管理 IM 机器人渠道。
- 管理网站嵌入渠道。
- 管理共享空间、共享智能体禁用状态。
- 查看工作区审计日志。
- 编辑工作区内任意知识库和智能体。

不可执行：

- 删除工作区。
- 重置工作区 API Key。
- 修改工作区成员角色。
- 移除工作区成员。
- 邀请工作区成员。

---

## 7. Contributor 操作说明

Contributor 是内容建设者。

可执行：

- 创建知识库。
- 上传文件、URL、手动内容到自己创建的知识库。
- 编辑、删除、重新解析自己知识库里的文档。
- 管理自己知识库里的 FAQ、标签、分块、Wiki 页面。
- 创建智能体。
- 编辑、删除自己创建的智能体。
- 复制知识库或智能体。

受限：

- 不能编辑他人创建的知识库和智能体。
- 不能配置租户级模型、MCP、向量库、数据源、IM、嵌入渠道。
- 不能管理成员。

---

## 8. Viewer 操作说明

Viewer 是只读使用者。

可执行：

- 查看有权限的知识库。
- 查看知识条目、文档预览、分块。
- 下载有权限的知识文件。
- 使用知识库问答。
- 使用可见智能体对话。
- 搜索知识库和历史会话。
- 查看自己会话并管理自己的会话记录。
- 收藏、置顶自己可见的资源。
- 查看公开给自己的共享资源。

不可执行：

- 创建或修改知识库。
- 上传、删除、重新解析文档。
- 创建或修改智能体。
- 修改模型、MCP、数据源、IM 等配置。
- 管理成员或权限。

## 9. 常见业务操作流程

### 9.1 创建知识库并上传文档

适用角色：Contributor、Admin、Owner。

1. 进入知识库列表。
2. 点击创建知识库。
3. 填写名称、描述和知识库类型。
4. 进入知识库详情。
5. 上传文件、URL 或手动内容。
6. 等待解析完成。
7. 在问答页测试检索效果。

### 9.2 创建智能体

适用角色：Contributor、Admin、Owner。

1. 进入智能体列表。
2. 点击创建智能体。
3. 选择智能体类型或预设。
4. 配置关联知识库、模型、工具和提示词。
5. 保存后进入对话测试。

### 9.3 使用知识库问答

适用角色：Viewer 及以上。

1. 进入聊天或知识库问答页面。
2. 选择知识库或智能体。
3. 输入问题。
4. 查看回答和引用来源。
5. 如结果不理想，联系内容维护者检查文档和索引。

### 9.4 配置外部数据源同步

适用角色：Admin、Owner。

1. 进入知识库设置。
2. 打开数据源标签页。
3. 选择数据源类型。
4. 填写凭证和同步参数。
5. 测试连接。
6. 选择资源范围。
7. 设置同步策略并保存。
8. 手动触发同步或等待定时同步。

钉钉数据源参考：

- [钉钉知识库和钉盘同步参数获取教程](./datasource/钉钉知识库和钉盘同步参数获取教程-给企业管理员.md)
- [钉钉同步参数填写表](./datasource/钉钉同步参数填写表-给企业管理员.md)

### 9.5 配置 IM 机器人

适用角色：Admin、Owner。

1. 进入智能体或 IM 集成配置。
2. 新增 IM 渠道。
3. 选择平台，例如飞书、企业微信、钉钉、Slack、Telegram。
4. 填写平台凭证。
5. 配置回调或 Stream 模式。
6. 保存并启用。
7. 到 IM 中测试提问。

### 9.6 配置网站嵌入 Widget

适用角色：Admin、Owner。

1. 进入智能体嵌入渠道配置。
2. 创建嵌入渠道。
3. 设置允许的来源域名。
4. 获取发布 Token 或嵌入代码。
5. 在目标网站接入并测试。

## 10. 共享空间使用说明

共享空间用于跨工作区共享知识库和智能体。

一般规则：

- 共享空间有自己的成员和权限，和工作区 RBAC 是两套机制。
- 共享空间不会改变资源归属。
- Viewer 不能把资源共享出去。
- Contributor 只能共享自己创建的资源。
- Admin 和 Owner 可管理工作区内资源的共享。

分享资源：

1. 打开知识库或智能体详情。
2. 进入共享设置。
3. 选择目标共享空间。
4. 设置只读或可写权限。
5. 保存。

## 11. 数据权限边界

### 11.1 工作区内

- Viewer：只读。
- Contributor：可维护自己的资源。
- Admin：可维护工作区全部资源。
- Owner：Admin 能力 + 成员/API Key/工作区删除等最高权限。

### 11.2 共享空间

跨工作区访问必须同时满足：

- 资源已共享到对应共享空间。
- 当前用户所在工作区是该共享空间成员。
- 共享权限允许当前操作。
- 源资源和目标操作没有被更高层 RBAC 阻止。

### 11.3 API Key

API Key 适合系统集成和脚本调用：

- 在所属工作区内通常按 Admin 处理。
- 不建议给普通个人保存。
- 泄露后应由 Owner 重置。

## 12. 常见问题

### 12.1 为什么我看得到按钮但点不了？

通常是当前角色不足，或你不是该资源创建者。查看用户菜单里的当前工作区角色，必要时联系 Owner 或 Admin。

### 12.2 为什么 Contributor 不能改别人的知识库？

Contributor 的权限设计是“维护自己创建的资源”。他人资源对 Contributor 通常是只读。

### 12.3 为什么我不能邀请成员？

邀请、移除、修改成员角色是 Owner 权限。

### 12.4 为什么我不能配置模型或数据源？

模型、数据源、MCP、IM、向量库等都包含租户级配置或敏感凭证，需要 Admin 或 Owner。

### 12.5 为什么共享给我的知识库不能编辑？

可能原因：

- 分享时只给了只读权限。
- 你在共享空间里是只读角色。
- 源工作区 RBAC 不允许跨工作区写入。
- 该资源本身不支持当前操作。

### 12.6 为什么登录后没有看到预期工作区？

可能原因：

- 还没有接受邀请。
- 当前账号不在该工作区。
- 浏览器缓存了上次工作区，需要手动切换。
- OIDC 登录使用了不同邮箱或账号标识。

## 13. 管理建议

| 人员类型 | 推荐角色 |
|---|---|
| 平台运维 | SystemAdmin |
| 部门负责人 / 知识负责人 | Owner |
| 系统配置和集成维护人员 | Admin |
| 内容维护人员 | Contributor |
| 普通查询和业务使用者 | Viewer |
| 脚本和自动化系统 | API Key，单独保管 |

建议：

- 不要把所有人都设为 Admin。
- 不要多人共用同一个高权限账号。
- 定期清理离职或不再使用的成员。
- 对外部数据源、模型、IM、MCP 凭证做最小授权。
- 高风险操作前先导出或备份。
